# 5. Product Excellence

## Product Mindset
Developers build solutions, not just features.

## Translating User Needs
- Understand user context
- Ask clarifying questions
- Validate assumptions

## Product Strategy
- Know what the project is *not*
- Focus on value delivery

## Acceptance Criteria
Features must be clearly verifiable:
- TRUE = meets expectations
- FALSE = does not

## User Feedback
- Incorporate feedback early
- Iterate intentionally

## Long-Term Maintainability
Favor simplicity over cleverness.
