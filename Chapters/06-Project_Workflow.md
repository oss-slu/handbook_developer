# 6. Project Workflow

## Agile Cadence
- Two-week sprints
- Planning → Execution → Review
- Demos are required
- Reflection is expected

## Trunk-Based Development
- Keep branches short-lived
- Merge frequently
- Avoid long-running divergence

## GitHub Tools
- Issues for work tracking
- Projects for prioritization
- Clear acceptance criteria

## Pull Requests
- One PR = One purpose
- Clear description required
- Respond to reviews promptly
