# 3. Community Engagement

## Open Source Culture
Open source values transparency, learning, and shared ownership.

## Contributing to Projects
- Follow contribution guides
- Respect maintainers’ time
- Start with smaller contributions

## Issue Triage
- Label issues clearly
- Provide reproduction steps
- Close resolved or stale issues responsibly

## External Feedback
- Assume positive intent
- Respond professionally
- Escalate when necessary

## Code Ownership & Maintenance
Ownership means responsibility, not control.
Maintainers ensure continuity and quality.

## Travel Stipend Program
Participation in conferences and meetups:
- Builds professional networks
- Strengthens open-source identity
- Encourages public leadership
