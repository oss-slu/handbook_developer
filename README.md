# Open Source with SLU – Developer Handbook

This repository contains the **general Developer Handbook** for the *Open Source with SLU* program.

The handbook defines professional standards, collaboration norms, and software engineering expectations for **all developers and contributors**, regardless of project.

## Purpose
This handbook exists to:
- Support consistent, professional development practices
- Encourage sustainable open-source contribution
- Provide clear expectations for collaboration and quality
- Enable long-term project health across cohorts

## How to Use This Handbook
- Read chapters sequentially if you are new
- Refer to specific chapters as needed during development
- Use the appendices for checklists, templates, and definitions

This handbook is a **living document** and may evolve as the program grows.
